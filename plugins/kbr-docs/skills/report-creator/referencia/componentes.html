Regra do histórico — só quando Published

O Histórico de revisões e os Detalhes das versões só recebem uma nova entrada quando o documento é promovido a Published. Edições em Draft ou Em revisão não geram entrada — apenas atualizam o campo Atualizado em e, se for o caso, a Versão. Assim tanto a tabela quanto o detalhamento refletem o que de fato foi publicado, não cada rascunho.

Visão geral#

Esta variação não substitui o sistema flat — é uma alternativa para contextos onde a documentação convive com painéis de produto (admin, BI, configurações) que demandam uma estética mais "soft UI". Tudo se mantém compatível com os tokens {{PROJETO}} core.

i
Quando usar esta variação

Painéis internos, dashboards executivos, ferramentas de configuração. Para documentação pública e runbooks operacionais, prefira a variação flat — mais densidade visual e legibilidade contínua.

Tokens — light vs dark#

Os tokens são semânticos (--surface, --text, --info), não literais. O atributo data-theme em <html> troca o conjunto inteiro. Componentes não conhecem o tema atual — só consomem tokens.

›
Persistência

A escolha é gravada em localStorage sob a chave kinto-theme. Sem escolha explícita, respeita prefers-color-scheme do sistema.

Campos & filtro#

Input de texto/filtro no estilo dos pills (mesma superfície e borda), porém com cantos discretos (--r-sm). Hover/foco na cor primária; respeita os temas claro e escuro. Classes equivalentes: .filter ou .field (modificadores --sm, --block).

FAQ#

Por que adotar a versão rounded em vez da flat?

Quando a doc convive com produto interno (admin, BI), a estética rounded reduz o atrito visual entre páginas. Para docs públicas, a flat ainda é a recomendada.

O tema escuro afeta a paleta primária da marca?

Sim — em dark mode o azul #00708D é trocado por #4AB5D0 (mesma família, luminosidade ajustada para contraste WCAG AA sobre surface escuro).

Como reaproveitar os tokens em outro projeto?

Copie os blocos :root[data-theme="light"] e [data-theme="dark"] + o snippet JS de toggle. Os componentes que consomem só tokens semânticos seguem o tema automaticamente.
